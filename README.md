# MusharaqaHUB Landing Page

Production-ready single-page landing site for MusharaqaHUB, built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- App Router

## Local setup

```bash
npm install
```

## Run in development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```

## Deploy to Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Import the repository into [Vercel](https://vercel.com/new).
3. Keep the default Next.js project settings.
4. Deploy.

Vercel will detect Next.js automatically and build the app with the standard production workflow.
