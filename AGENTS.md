# AGENTS.md

## Project intent
This repository is for the MusharaqaHUB landing page.

## Product direction
Build a premium institutional landing page for a Shariah-compliant real-world asset infrastructure platform.

## Design rules
- Institutional, premium, restrained tech
- Avoid flashy crypto aesthetics
- Prefer elegant whitespace, subtle borders, muted accents
- Prioritize credibility and calm visual hierarchy

## Engineering rules
- Use Next.js + TypeScript + Tailwind CSS
- Keep components modular and readable
- Use App Router
- Avoid unnecessary dependencies
- Ensure responsive behavior
- Ensure production build passes
- Keep content easy to edit later

## Workflow rules
- Inspect repo before changing files
- Make direct edits
- Run build validation before finishing
- Fix your own errors before returning
- Do not add fake data, fake traction, or fake partner logos
